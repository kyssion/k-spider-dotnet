# 完成定义（DoD）

> 状态：已确认
> 最后更新：2026-11-09
本文范围：交付前必须核对的清单。条目本身以各自唯一权威为准，本文只回答“要检查什么、去哪里核对”。

## 使用方式

“代码写完”不等于完成。任一项未满足时，在交付说明中明确列出，不得默认通过。清单按改动类型取用；不适用的条目写“不适用”并说明原因。

## 当前阶段特别说明

阶段与进度以 [roadmap.md](../00-overview/roadmap.md) 为准；本清单只回答交付前检查什么。
`./scripts/verify.sh` 同时运行 v2 架构/契约守卫、gRPC 契约测试与 v1 过渡测试；未覆盖项必须在交付说明列出。
以下情况都不算“完成”：

- 用 v1 过渡测试通过代替 v2 功能验证；
- 用“骨架能启动”代替“业务已实现”；
- 用文档里的目标设计代替代码里的现状；
- 用注释断言、跳过用例或放宽断言让门禁变绿。

涉及 v2 服务行为的改动，未覆盖项必须在交付说明中列出，不能声称已验证。
测试边界见 [testing.md](../30-guides/testing.md)「当前门禁与目标门禁」。

## 通用清单

- [ ] 改动范围与规格/ADR 一致，没有顺手改动无关代码；
- [ ] 没有删除、跳过或弱化测试，没有为通过构建而注释断言；
- [ ] 文档已同步：权威文档、状态块、目录索引、待确认清单；范围/阶段变化时同步
      [roadmap.md](../00-overview/roadmap.md)，新发现或关闭问题同步
      [issue-tracker.md](../00-overview/issue-tracker.md)；
- [ ] 没有引入未确认的依赖、框架或公共接口变更；
- [ ] 没有提交真实凭据、Cookie、个人数据或临时调试输出；
- [ ] `./scripts/verify.sh` 全绿，且保留实际命令与输出；
- [ ] 自己启动的后台进程已停止，端口已确认释放；
- [ ] 交付说明按 [collaboration-model.md](collaboration-model.md) 的四段式给出。

## 按改动类型补充

### 功能

- [ ] 规格含目标、非目标、验收标准，完成后补验收结论；
- [ ] 验收标准逐条有对应测试或明确标注未覆盖；
- [ ] 相关架构文档的“当前状态”与实现一致，没有把目标设计写成现状。

### 契约 / 数据模型 / DDL

- [ ] 待确认项已登记，确认后写 ADR；
- [ ] 已确认 ADR 的正文未被修改；决策变化写新 ADR，进度写 roadmap（[0009-adr-does-not-track-progress.md](../20-adr/0009-adr-does-not-track-progress.md)）；
- [ ] 权威文档与 DDL 同步，物理结构与语义分工没有混写；
- [ ] 前后端契约变更按 [change-protocol.md](change-protocol.md) 的顺序完成；
- [ ] 破坏性变更记录了迁移与回滚方案。

### 修复

- [ ] 有可复现步骤或失败用例；
- [ ] 有回归测试，修复后原失败用例通过；
- [ ] 与规格/契约的差异已说明。

### 文档 / 配置

- [ ] 文档引用的路径、命令和脚本真实存在；
- [ ] 文档没有复制其他权威文档的正文，只保留链接与必要说明；
- [ ] 新目录/新文件已登记到所属目录 `README.md` 和 [docs/README.md](../README.md) 的目录索引；
- [ ] 文档检查通过。

### 前端 / 后端服务

- [ ] 新增端点、字段、错误码、配置键已登记到对应权威文档；
- [ ] 测试分层符合 [testing.md](../30-guides/testing.md)；
- [ ] 本地使用 `--skip-tests` 时，已在交付说明中标注跳过项；交付前以完整校验为准。

## 交付前自检命令

```bash
./scripts/verify.sh
git status --short
./scripts/stop.sh
git grep -n -E "TODO|FIXME" -- src web/src ':!src/k-spider-dotnet-old' || true
```

`stop.sh` 按端口收尾并复查 5094 / 5173 / 5899，未释放时非零退出；`git grep` 只扫现行代码与
前端源码，v1 归档不计入。

## 未完成时

- 在交付说明的“结论”写“部分完成”或“阻塞”；
- 列出未完成项、原因、已尝试的命令与输出；
- 需要所有者决策的，按 [collaboration-model.md](collaboration-model.md) 的升级条件提问，不自行补假设。
