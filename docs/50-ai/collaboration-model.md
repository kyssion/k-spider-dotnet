不默认通读全部文档或全部技能。

## 交付要求

- 先给方案（目标、做法、影响面），确认后再改；
- 代码、DDL、契约、配置、脚本变更必须在同一次改动中同步文档和状态日期；
- 不把目标设计写成现状；未确认事项标【待确认】并登记到 `20-adr/`；
- 完成前运行 `./scripts/verify.sh`，并以实际命令结果为准；
- 提交/推送按项目所有者的明确指示执行。

Definition of Done 见 [definition-of-done.md](definition-of-done.md)。
