# 功能梳理

DataForge 的能力全集。按域组织；每条是**功能规格**（新系统必须承接的能力），不含历史实现细节（源站侦察结论与踩坑记录在 git 历史中）。

### 1.2 抓取能力

- **四种抓取策略**：游标翻页（页码/时间游标，边界语义可配置）、全量对账、窗口快照、键增量；
- **多段回填**：列表 → 详情两段/三段（中间态归执行引擎，业务行只存数据语义）；
- **翻页控制**：自适应停止（翻到存量区间即停）、停机回补上限、每轮批量上限；
- **多栏目**：栏目资源反查（频道参数/分类号按栏目传入）、伪栏目（同站第二列表族）；
- **编码与解析**：JSON / HTML（结构化片段：段落/图片/表格/列表）/ GBK 等响应编码；
- **条目级过滤**：广告/站外跳转/付费专享/非内容形态按规则跳过或兜底。

### 1.3 反爬验证

- **识别**：HTTP 门禁（403/401/412/429/503+Retry-After/3xx）、Cloudflare 类 JS 挑战、JS cookie 门禁（加速乐/阿里云盾/瑞数类）、浏览器检查页、验证码（滑块/图形/短信）、载荷级风控（200 但 envelope 报风控）；
- **通过**：浏览器过挑战导出 cookie 回放 HTTP 链路（默认放行）；滑块按源显式放开；图形/短信只识别并升级告警；
- **会话与克制**：会话按主机缓存复用、CookieContainer 回放（不手动拼 Cookie 头）、同主机串行、失败冷却（限流按源站 Retry-After 退避）、按源策略（放行集合可追加/收窄/关闭）；
- **防误判**：内容型识别器只对 HTML 生效、风控词只扫 envelope、中文泛词需配合表单元素、词表不放中性词；
- **平台能力**：全局限流器（按源令牌桶）、代理池（插件位）、浏览器渲染服务（按需启动）。

## 二、存储功能

- 数据集注册（schema 声明、写入语义、保留策略）与记录统一表；
- 写入三模式：追加 / 按键 upsert（发布即终态）/ 哈希修订（内容真变才更新）；
- 变更检测（content_hash）与行版本（version）；
- 投影列：表达式索引 → 热字段提升实物列；
- 分区（event_time）与保留期治理；原始响应保留与解析重放窗口；
- 分发：dataset 级同步（新行按 Id 水位 + 已有行按 update_time 双键水位）。

## 三、分析功能

- 语义层：维度/指标/视图声明式注册；
- 查询引擎：语义查询 → SQL，查询预算制（无硬性时间窗），大查询异步化；
- 物化引擎：物化视图 / 预聚合表 / 派生表（血缘登记、刷新策略、保留期）；
- 分析 API + 前端图表（趋势/分布/词频/排行）；
- 洞察插件位（远期）：NLP、AI 摘要/RAG 作为派生表生产者。

## 四、控制台功能

- 总览：任务状态、管线积压、快讯实时性、反爬告警、节点状态；
- 源管理：源/数据集清单与健康状态；
- 数据浏览：schema 驱动的动态表格（筛选/分页/联查）；
- 任务控制：手动触发/暂停/恢复（指令表异步受理）；
- 派生表管理：定义/血缘/刷新触发；
- 分析看板：视图驱动的图表；
- 数据重放：按原始响应重跑解析（引擎能力，非一次性工具）。

## 五、运维功能

- 配置：多环境（Development/Test/Production）+ `K_SPIDER__` 环境变量覆盖 + 代码默认值；
- 健康探测：注册即覆盖（接口可用性/新鲜度/积压/反爬冷却），阈值按数据节奏配置；
- 告警：通道插件化（日志/飞书/Webhook），规则注册；
- 部署：自包含发布（只带目标环境配置）、systemd 托管、优雅停机；
- 启动自检：库对象幂等补齐、批量 upsert 唯一约束自检。

## 六、平台边界（明确不做）

- 不做登录墙/付费内容的突破（无凭据不抓）；
- 不做跨源内容级归并（按去重键隔离，跨源关联是分析层职责）；
- v1 不做多节点集群（契约预留，单机形态）；
- 图片只记地址不下载（除非派生表消费需要）。
