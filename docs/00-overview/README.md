# 概览索引

[vision.md](vision.md) 为唯一来源；模块落地状态以根 [README.md](../../README.md) 状态表为准。

| 文档 | 回答的问题 |
| --- | --- |
| [vision.md](vision.md) | 平台定位、目标与非目标、成功标准 |

| [features.md](features.md) | 采集、存储、分析、控制台、运维能力与数据源清单 |
| [glossary.md](glossary.md) | 术语与统一用语 |

阅读顺序：vision → roadmap → issue-tracker → features → glossary。待确认事项见
[20-adr/README.md](../20-adr/README.md)。
